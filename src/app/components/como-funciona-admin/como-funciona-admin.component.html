lightbulb Consejos Importantes
  • Los docentes deben crearse antes que las materias, ya que las materias necesitan un profesor asignado.
  • Las materias deben crearse antes que las carreras, ya que las carreras asignan materias a los cursos.
  • Los alumnos pueden registrarse en cualquier momento, pero deben tener una carrera asignada.
  • Los cursos se crean automáticamente cuando creas una carrera usando el wizard.
  • Puedes importar alumnos desde Excel para agilizar el proceso de registro.
  • Revisa la sección de Auditoría para ver todos los cambios realizados en el sistema.
