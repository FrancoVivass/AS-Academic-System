# Logos de Instituciones

## Ubicación del Logo de Instituto Paula Robles

Para que el logo del **Instituto Paula Robles** aparezca correctamente en el sistema, coloca el archivo del logo en esta carpeta con el siguiente nombre:

### 📁 Ruta del archivo:
```
src/assets/instituciones/paula-robles-logo.png
```

### 📋 Especificaciones recomendadas:
- **Formato:** PNG (preferido) o JPG
- **Tamaño recomendado:** 200x200px o más grande
- **Fondo:** Preferiblemente transparente o blanco
- **Resolución:** Mínimo 300 DPI para buena calidad

### 🎨 Diseño:
- El logo se mostrará con fondo blanco y borde redondeado
- Se recomienda que el logo tenga un diseño que contraste bien con el fondo blanco
- Los colores del logo deben combinar con los colores bordo (#800020, #722F37) de la institución

### ✅ Verificación:
Una vez que coloques el logo en esta ubicación, aparecerá automáticamente en:
- Página de login
- Página de registro
- Header de la aplicación (cuando estés logueado)
- Página de selección de instituciones

### 📝 Nota:
Si el logo no se encuentra, el sistema mostrará un ícono de fallback (business icon) en su lugar.
